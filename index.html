📖 展開完整文字版設定教學
Step 0｜安裝 Git（只需做一次）
1. 前往 git-scm.com/download/win 下載安裝檔
2. 打開安裝程式，全程按「Next」保持預設值即可，最後按「Install」
3. 裝好後不用特別打開它，之後雙擊 bat 檔案時會自動呼叫

Step 1｜建置 GitHub（只需做一次）
1. 前往 github.com 申請帳號
2. 建立 repo，取名 office-translation
3. Repo → Settings → Pages → Source 選「Deploy from a branch」→ Branch 選 main / (root) → Save
4. 網站網址會是 https://dvorak0727.github.io/office-translation/

Step 2｜下載工具包到電腦
點上方「⬇️ 下載完整工具包 ZIP」按鈕，解壓縮後會看到： translate-editor.html、build_index.ps1、上傳到GitHub.bat、第一次設定.bat、建立桌面捷徑.bat、AGENTS.md 等檔案。 或雙擊「第一次設定.bat」用 git clone 下載（電腦需先安裝 Git）。

Step 2.5｜建立桌面捷徑（強烈建議，只需做一次）
雙擊「建立桌面捷徑.bat」，會自動在桌面產生兩個圖示： 「① 翻譯上稿工具」與「① 上傳翻譯到網站」。 ⚠ 注意：瀏覽器基於安全機制，無法直接執行電腦裡的 .bat 程式 （例如用瀏覽器打開資料夾點 .bat 只會顯示程式碼文字，不會真的執行）。 建立好桌面捷徑後，之後永遠只要在「桌面」雙擊圖示即可，不用再透過瀏覽器找資料夾。

Step 3～6｜日常上稿流程
雙擊 translate-editor.html → 填「發文處室／標題／日期」→ 貼中文原文 → 到 ChatGPT 或 Gemini 網頁請它翻譯成英文/越南文 → 貼回表單對應欄位 → 核對翻譯內容無誤 → 按「產生網頁檔」（會自動下載到 docs 資料夾）。

Step 7｜上傳
雙擊「上傳到GitHub.bat」，跑完後網站會自動更新，外師打開網址就能看到最新文件。
